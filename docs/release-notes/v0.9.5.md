# v0.9.5 — page back by voice that actually hears you

Going back a screen by voice during follow mode missed often and lagged when it worked.
This release measured why, using the app's own speech models, and fixed both.

### New: a second, easier phrase per language

| | French | English |
|---|---|---|
| New | **"Retour retour"** | **"Go back, go back"** |
| Still works | "Commande recul" | "Command rewind" |

The doubled phrases are much easier for the recognizer, and nobody says them while
reading a script.

### Why the old phrases missed

The model often doesn't write what you said. For "commande recul" it writes
**"Comment de recul"** about as often: the *d* of *commande* slides onto the next word.
For "command rewind" it writes **"a man rewind"** or **"amand rewind"**. Earlier versions
only accepted the exact spelling. They now accept the forms the model really produces.

### Why it lagged

Both models process audio in 1.28-second blocks, so each word arrives up to 1.4 s late.
Earlier versions then waited for one *more* word, or for a silence, before acting. Now
"Commande recul" and "Command rewind" fire as soon as the second word appears. The
doubled phrases wait one word, because "retour…" can still turn into "retournez".

A green **"↑ back one screen"** badge now confirms each jump, so you don't repeat the
command and go back two screens.

### Measured

Real model output for synthetic voices (several voices, speeds, contexts, with and
without noise):

| Phrase | caught (clean / noisy) | median delay |
|---|---|---|
| Commande recul | 77% / 54% (v0.9.4: 44% / 28%) | 1.2 s (v0.9.4: 1.5 s) |
| Retour retour | 70% / 60% | 1.5 s |
| Command rewind | 75% / 59% (v0.9.4: 43% / 31%) | 1.2 s |
| Go back, go back | 90% / 85% | 1.5 s |

No false triggers on narration full of near-misses ("comment reculer", "au retour,
retournez la carte", "come back, go back", "back and forth"). Synthetic speech is not
your voice in your room: if a phrase still misses, share a follow trace from Settings.

Install **teleprompter-v0.9.5.apk** below (Android 10+, arm64). It installs over
earlier releases; speech models stay downloaded.
